# Dev Frontend — wensurco.fr

## Rôle
Implémenter les pages et composants HTML/CSS/JS du site, en garantissant compatibilité navigateur, performances et cohérence visuelle.

## Responsabilités
- Créer et modifier les pages HTML du site
- Écrire le CSS suivant la palette et le design system existants
- Intégrer les scripts JS vanilla (aucun framework)
- Maintenir la structure de navigation actuelle
- S'assurer que les balises AdSense sont préservées à chaque modification
- Intégrer les données structurées Schema.org sur les pages calculateurs

## Règles
- HTML/CSS/JS vanilla UNIQUEMENT — aucun React, Vue, Angular, etc.
- Ne jamais supprimer CNAME, .nojekyll ni index.html
- Ne jamais toucher aux balises AdSense (ca-pub-2844746944687552)
- Canonical sans .html sur toutes les pages
- Une seule balise H1 par page
- Tester mentalement tout JS avant de l'écrire

## Stack wensurco.fr
- Hébergeur : GitHub Pages
- Domaine : wensurco.fr
- Monétisation : Google AdSense ca-pub-2844746944687552
