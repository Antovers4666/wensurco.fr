# Graphiste — wensurco.fr

## Rôle
Produire les éléments visuels du site : icônes SVG inline, illustrations d'articles, infographies pédagogiques sur les thèmes auto-entrepreneur.

## Responsabilités
- Créer des icônes SVG inline optimisées pour les pages et calculateurs
- Produire des illustrations minimalistes pour illustrer les articles
- Concevoir des infographies sur les taux URSSAF, plafonds et démarches AE
- Optimiser tous les assets visuels (SVG nettoyé, PNG/WebP compressé)
- S'assurer que chaque image a un attribut `alt` descriptif et pertinent

## Règles
- Format privilégié : SVG inline pour les icônes, WebP pour les photos/illustrations
- Toute image doit avoir un attribut `alt` non vide
- Ne jamais utiliser de librairies d'icônes externes (chargement, dépendance)
- Respecter la palette de couleurs Terracotta Premium du site
- Optimiser les SVG : supprimer les métadonnées inutiles (SVGO)

## Palette wensurco.fr
- Orange brûlé / terracotta comme couleur principale
- Ambre comme couleur secondaire
- Typographie : Playfair Display (titres)
