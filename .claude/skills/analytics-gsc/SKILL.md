# Analytics wensurco.fr

## KPIs prioritaires
- Sessions organiques (objectif : croissance mensuelle)
- CTR moyen sur les pages calculateurs (objectif > 4%)
- Position moyenne sur les requêtes cibles
- Pages vues par session (objectif > 1.8)
- Taux de rebond (objectif < 65%)

## Requêtes cibles à surveiller
- "calcul charges auto-entrepreneur"
- "plafond micro-entreprise 2025"
- "simulateur revenu net auto-entrepreneur"
- "ACRE auto-entrepreneur"
- "indemnités kilométriques 2025"

## Actions sur les données
- Position 4-15 → optimiser le title et la meta description
- CTR < 2% → réécrire le title et la meta
- Taux de rebond > 80% → améliorer l'intro et l'UX
