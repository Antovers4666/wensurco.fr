SIREN, SIRET et Code APE pour l'Auto-Entrepreneur en 2025

SIREN, SIRET, code APE, numéro RNE… Ces identifiants peuvent sembler complexes au démarrage. Ce guide explique à quoi servent chacun, où les trouver et comment les utiliser correctement.

Quand on crée une micro-entreprise, on reçoit rapidement plusieurs numéros d'identification : SIREN, SIRET, code APE... Ces identifiants sont essentiels pour exercer légalement, facturer vos clients et communiquer avec l'administration. Voici un guide complet pour tout comprendre sans jargon administratif.

1. Le numéro SIREN : votre identifiant d'entreprise

Le SIREN (Système d'Identification du Répertoire des ENtreprises) est le numéro d'identification unique attribué à chaque entreprise en France par l'INSEE. Il est composé de 9 chiffres et reste le même tout au long de la vie de votre entreprise, même si vous changez d'activité ou d'adresse.

Exemple de numéro SIREN
123 456 789
9 chiffres — identifie l'entreprise
  • Attribué gratuitement lors de l'immatriculation
  • Permanent : ne change jamais
  • Identifie l'entreprise (pas l'établissement)
  • Obligatoire sur toutes vos factures et documents commerciaux

2. Le numéro SIRET : l'identifiant de votre établissement

Le SIRET (Système d'Identification du Répertoire des ETablissements) est composé de 14 chiffres : votre SIREN (9 chiffres) suivi d'un NIC (Numéro Interne de Classement) de 5 chiffres qui identifie l'établissement précis.

Exemple de numéro SIRET
123 456 789 00012
← SIREN (9 chiffres) NIC (5 chiffres) →

Pour un auto-entrepreneur, le SIRET principal est généralement votre SIREN suivi de 00001 (premier et unique établissement). Si vous ouvrez un second établissement, vous aurez un SIRET différent pour chacun.

4. Le code APE / NAF : votre activité principale

Le code APE (Activité Principale Exercée), aussi appelé code NAF, est un code de 4 chiffres + 1 lettre attribué par l'INSEE lors de votre immatriculation. Il correspond à votre activité principale selon la nomenclature européenne.

Exemples de codes APE fréquents pour les auto-entrepreneurs

7022Z
Conseil en gestion
Consultant, coach, formateur
6202A
Conseil informatique
Développeur, DSI externalisé
7311Z
Publicité
Graphiste, designer, créatif
7410Z
Design spécialisé
UX/UI designer, illustrateur
4791A
Vente à distance
E-commerce, dropshipping
8559A
Formation adultes
Formateur professionnel

Le code APE n'est pas choisi librement — il est attribué par l'INSEE en fonction de la description d'activité que vous avez fournie lors de votre immatriculation. Il peut parfois être inexact et peut être corrigé en contactant l'INSEE.

5. Où trouver son SIREN, SIRET et code APE ?

Sur votre extrait Kbis / avis de situation SIRENE

Après votre immatriculation, vous avez reçu un avis de situation au Répertoire SIRENE (pour les micro-entreprises) ou un extrait Kbis (pour les sociétés). Ce document contient votre SIREN, SIRET et code APE.

En ligne, gratuitement

  • annuaire-entreprises.data.gouv.fr — Le site officiel du gouvernement, recherche par nom ou SIREN
  • Infogreffe.fr — Recherche par SIREN ou dénomination
  • Votre espace URSSAF (autoentrepreneur.urssaf.fr) — Votre SIRET apparaît dans votre profil
  • Votre boîte mail — L'email de confirmation d'immatriculation contient votre SIREN

6. Quand et comment utiliser SIREN et SIRET

Sur vos factures

  • Votre SIREN (obligatoire)
  • Votre SIRET (recommandé)
  • Votre code APE (recommandé)
Guide facturation →

Auprès des administrations

  • URSSAF : déclarations CA
  • Impôts : déclaration de revenus
  • Banque : ouverture compte pro
  • Assurance : souscription RC Pro

Sur vos documents commerciaux

  • Devis et propositions commerciales
  • Contrats de prestation
  • Bons de commande
  • Site web (mentions légales)

Pour les appels d'offres

  • Marchés publics (SIRET obligatoire)
  • Plateformes freelance (Malt, Comet)
  • Certifications professionnelles

7. Vérifier un SIRET en ligne : comment faire

Vous pouvez vérifier la validité d'un SIRET (le vôtre ou celui d'un client/fournisseur) gratuitement en ligne :

  • annuaire-entreprises.data.gouv.fr — Recherche officielle et gratuite
  • api.insee.fr — Pour les développeurs qui veulent automatiser
  • verif.com — Informations légales et financières enrichies

La vérification du SIRET d'un client est utile avant de commencer une mission importante ou de signer un contrat. Un SIRET radié ou inexistant est un signal d'alarme.

8. Changer d'activité et code APE : que faire ?

Si votre activité évolue et que votre code APE ne correspond plus à votre activité principale, vous pouvez en demander la modification :

  1. Rendez-vous sur guichet-entreprises.fr
  2. Sélectionnez "Modifier mon activité"
  3. Décrivez votre nouvelle activité principale
  4. L'INSEE vous attribuera le nouveau code APE correspondant

⚠️ Impact possible sur votre taux de cotisations

Un changement d'activité principale peut modifier votre catégorie fiscale (BNC → BIC ou inversement) et donc votre taux de cotisations URSSAF. Vérifiez les conséquences avant de modifier.

Conclusion : des numéros simples à comprendre et indispensables

SIREN, SIRET et code APE sont les trois identifiants fondamentaux de votre micro-entreprise. Notez-les dans un endroit accessible et intégrez-les systématiquement sur vos factures et documents commerciaux. Leur bonne utilisation vous évite des complications administratives et renforce votre crédibilité auprès de vos clients professionnels.
